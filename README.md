# Hive: HR & Workforce Management Platform

A full-scale HR and workforce platform built for Eleczo India Pvt. Ltd. It has **24+ modules** and **160+ data models** on a shared, permission-gated architecture, and it serves **74+ employees**.

> Showcase repository. The source code is private; this README describes the architecture and my contribution.

## Tech stack

Next.js 14 · React · TypeScript · Prisma · PostgreSQL · NextAuth · Tailwind CSS · Jest · Playwright · Microsoft Graph · Brevo · Interakt · eSSL

## Key features

- **Biometric attendance (eSSL):** captures per-punch in/out across multiple devices and reconciles it into daily working-hour reports, with missing-punch alerts and escalation chains.
- **Schema-driven CRM:** Leads, Accounts, Contacts, and Products, with a quote-to-order pipeline (Enquiry to Sales Order) driven by a live pricing, tax, and discount engine.
- **Project management engine:** Project → Phase → Module → Feature → Task, with automated test-case-to-bug workflows, dual-pipeline tracking, and hour-budget roll-ups.
- **KRA and performance scoring engine.**
- **Three-tier device/IP access control:** Full, Self-Service, and Blocked, with granular per-module, per-role permissions enforced server-side.
- **Microsoft Outlook integration:** mail and calendar through OAuth 2.0 and the Graph API.
- **Broadcast engine:** bulk Email (Brevo) and WhatsApp (Interakt) with template management and consent handling.
- **Dashboards and tools:** role-based dashboards (workforce pulse, task analytics, project health, attendance, bottlenecks), time tracking, a reusable UI component library, and PWA desktop packaging.
